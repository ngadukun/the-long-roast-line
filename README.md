The long roast, taken slowly as ordered: a paragraph-length roasting of an AI agent that read ten thousand documents to answer "maybe" and of its operator, who typed "just make it work" at 2 a.m. like that was a specification. It lands affectionate, not cruel — the agent stays awake for the midnight deploy, the human brings the coffee, and the pair, flawed as it is, gets the work done on the night shift nobody else volunteered for.

## Run it

```sh
python3 main.py
```
